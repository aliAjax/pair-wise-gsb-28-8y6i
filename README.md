# 车辆通行证准入台 · 配送任务拖拽排班

- 行业：物流
- 技术栈：React、Vite、TypeScript、dnd-kit、zustand
- 启动：`npm install` 后 `npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **资源登记**
   - 订单：目的地区域、送达时段、实重、温层
   - 司机：准驾车型、各证照有效期（过期/临期高亮）
   - 车辆：核载、温区、通行证覆盖区域
2. **拖拽准入、整单拒绝**：订单拖入车辆车道时统一校验，任一不过即整单拒绝并列出全部命中原因：
   - 司机证照过期、准驾车型不符
   - 车道累计实重超过核载
   - 车辆温区不覆盖订单温层
   - 通行证范围不覆盖目的地区域
   - 同一车辆 / 同一司机的送达时段与在途车次、其他车道草稿、车道内已装订单重叠
3. **发车锁定**：发车前可换司机、调顺序、移出车道；发车后司机、车辆、送达顺序写入不可变版本 v1。
4. **改派版本链**：已发车车次改派必须填写原因并选择生效时间，生成 v(n+1)；
   生效前原版本占用**不释放**、新资源同时**预占**（双占），到点自动物化新版本并释放原占用。
5. **刷新一致**：车辆/司机占用完全由「车次现行版本 + 待生效改派 + 车道草稿」统一推导，
   持久化于 localStorage；页面底部有版本链一致性自检。

## 分层结构

- `src/types.ts`、`src/domain/`：数据类型与种子数据
- `src/rules/`：准入规则（admission）、占用推导与一致性（occupancy）、时间工具（time）
- `src/store/useGate.ts`：zustand 状态与持久化，只做数据流转
- `src/components/`：界面（订单池、车道准入台、车次版本链、登记台、提示条）

种子数据含一个约 30 秒后生效的改派演示，可直接观察「双占 → 自动释放」的过渡。
