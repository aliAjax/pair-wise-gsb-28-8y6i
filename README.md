# 车辆通行证准入台（配送任务拖拽排班扩展）

- 行业：物流
- 技术栈：React、Vite、TypeScript、Ant Design、dnd-kit、Zustand
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **订单**：区域、送达时段、实重、温层。
2. **司机登记**：准驾车型（A2/B2/C1）、驾驶证与货运资格证有效期、可押运温层（冷链资质）。
3. **车辆登记**：核载、车厢温区、通行证覆盖区域与有效期。
4. **拖拽准入**：待分配订单拖入车辆车道时执行全部规则——
   - 司机证照过期（驾驶证 / 资格证）、准驾车型不符、无对应温层资质；
   - 实重超过核载、车辆温区不支持订单温层；
   - 通行证过期或范围不覆盖目的地；
   - 同车送达时段重叠（半开区间，端点相接不算重叠）。
   
   任一不通过即**整单拒绝**，订单留在待分配池，并在「准入拒绝」台账留痕。
5. **发车锁定**：车道「整车发车」后，司机、车辆与车道顺序锁定（🔒），待发车任务仍可排序/撤回。
6. **改派版本链**：改派必须填写原因，生成新版本（`revising`）挂到目标车道占位；
   **原占用到修订批准生效才原子释放**；批准时用最新数据重新校验，不通过则版本驳回并留痕。
7. 刷新后车辆占用、版本链、拒绝留痕与当班司机选择通过 localStorage 持久化保持一致。

## 分层结构

```
src/
  data/      数据层：领域类型 + 常量/种子数据（无行为）
  rules/     规则层：准入校验、占用与版本链派生（纯函数，不依赖 React）
  state/     状态层：Zustand store，所有写入动作先过规则层并持久化
  ui/        界面层：车道、卡片、弹窗、台账（只渲染与派发动作）
```
